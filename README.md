## 🎯 Sobre o Projeto

Este repositório reúne os materiais, planilhas e notebooks desenvolvidos durante a **Aula 01** da trilha **Nerd Data Lab (Amazing Data IA Lab)**. O objetivo principal é conectar conceitos tradicionais de análise de dados no **Excel** (como `PROCV`, `SOMASE` e lógica condicional) com a automação e escalabilidade do **Python** utilizando a biblioteca `pandas`.
